# Rustlings

Rustlings is a collection of small exercises to get you used to writing and reading Rust code

`cargo install rustlings`

`rustlings -h`

`rustlings init`

## exercises

```sh
rustlings reset primitive_types4
rustlings reset primitive_types5
rustlings reset primitive_types6
rustlings reset vecs1
rustlings reset structs1
rustlings reset structs2
```
