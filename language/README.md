## RUST_BACKTRACE

The backtrace generated by a call to panic! displayed when the environment variable **RUST_BACKTRACE** is set.<sub>设置临时环境变量查看详细异常堆栈</sub>

```sh
# shell 当前以及子会话生效
export RUST_BACKTRACE=1

# powershell 当前以及子会话生效
$env:RUST_BACKTRACE=1

# cmd 当前会话生效
set RUST_BACKTRACE=1

# cmd 永久环境变量 当前会话不生效，setx最大支持1024字符
setx RUST_BACKTRACE=1
```
